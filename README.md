
# Hough Transform for Digital Image Processing

## Overview

This project implements several Hough Transform techniques for practical computer vision tasks.

The main algorithms are implemented mostly from scratch using NumPy and fundamental image processing operations.

## Main Tasks

- Traffic light detection and state classification using Hough Circles
- Lane detection using the Polar Hough Line Transform
- Object localization using the Generalized Hough Transform

## Main Methods

- Gaussian Filtering
- Sobel Edge Detection
- Hough Circle Transform
- Hough Line Transform
- Generalized Hough Transform
- Gradient-Based Voting
- R-Table Construction
- NumPy Vectorization

## Technologies

Python · Jupyter Notebook · NumPy · Matplotlib · OpenCV
